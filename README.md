# Semi-Automatic-Restroom-Cleaning-Robot-ArUco-Aligned-Teach-and-Playback-Arm-
Developed a low-cost restroom-cleaning robotic arm with OpenCV-based ArUco alignment and a Kotlin app for teaching and replaying cleaning paths. Also supports repetitive tasks, with initial work on phone-based colour-difference dirt detection. Designed as an affordable automation solution for Indian facilities.
